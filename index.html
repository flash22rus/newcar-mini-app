Курсы валют ЦБ РФ

Курсы будут загружены по дате расчёта. Если ЦБ недоступен, используется сохранённый резервный курс и это будет отмечено.
Источник: Банк России. Курс определяется по дате расчёта; для даты без публикации ЦБ возвращает ближайшую зарегистрированную дату. Для финального КП рекомендуем подтвердить курс на дату таможенного оформления.
